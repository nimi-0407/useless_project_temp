Chatn't v8

- Site name: Chatn't.
- E-Letter terminology uses E-Letter / E-Letters.
- Designed for testing multiple Chatn't windows on ONE computer.
- Each browser window gets its own Chatn't ID using sessionStorage, so opening a second window does not replace the first window's session.
- Start the server with npm.cmd install, then npm.cmd start.
- Open http://localhost:3000 in each window.
- Keep the Node server terminal running.
- Chat works between online windows on the same computer.
- E-Letters can be sent when the recipient window is closed; queued letters live in server memory while the server stays running.
